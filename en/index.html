📖 Usage Guide

1

Select Image File

Click the "Click to select image file" area to choose an image from your device. Supported formats include: JPEG, PNG, GIF, BMP, and WebP.

2

Choose Icon Size

Select one or more icon sizes as needed. Common sizes include 16×16, 32×32, 96×96, 256×256, etc. You can select multiple sizes at once, and the generated ICO file will contain all selected sizes.

3

Choose Icon Shape

Select your desired icon shape: Square (maintains original aspect ratio), Circle (circular crop), or Rounded Square (square with rounded corners).

4

Set Padding Option

If you selected the "Rounded Square" shape, you can enable the "padding" option, which will add appropriate padding around the icon to make it look more aesthetically pleasing.

5

Start Converting

Click the "Start Converting" button, and the tool will process your image in the browser and generate an ICO file. Once the conversion is complete, the file will automatically download to your device.
